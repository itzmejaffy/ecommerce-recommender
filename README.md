How to Run the Project

Prerequisites

* Python 3.10 or above
* Git (optional, if downloading the ZIP)
* Internet connection

Step 1: Download the Project

Clone the repository:

git clone https://github.com/itzmejaffy/ecommerce-recommender.git

Or download the ZIP from GitHub and extract it.

Step 2: Open the Project Folder

Open Terminal (Mac) or Command Prompt / PowerShell (Windows) inside the extracted project folder.

Step 3: Install Dependencies

Mac:

python3 -m pip install -r requirements.txt

Windows:

py -m pip install -r requirements.txt

Step 4: Run the Application

Mac:

python3 app.py

Windows:

py app.py

Step 5: Open the Application

Open your browser and visit:

http://127.0.0.1:5000

The E-Commerce Product Recommendation System will now be running locally.

Troubleshooting

* Make sure Python is installed correctly.
* Ensure you are inside the project folder before running commands.
* If a required package is missing, reinstall dependencies using the commands above.
* Keep the terminal window open while using the application.

Note

This application runs locally on the user’s computer. Each user must install the dependencies and start the application on their own device.
